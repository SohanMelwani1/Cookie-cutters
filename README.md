# Cookie-cutters
Lots of cookie cutters

In total there are 20 cutters
I made this to help me shape and cut cookies, making it much more convinient then to manually cut each corner and also since there are 20 cutters there are a few in different sizes to cut, I added a thick border in each of the cutters so that you can easily hold it and cut it. I also made the cutters sharp and thin in 1 side so it can easily slice the cookie with really little pressure. However you are free to scale it up to which ever size you like.
